# Snaka Sandbox

## How do I install these formulae?

`brew install snaka/sandbox/<formula>`

Or `brew tap snaka/sandbox` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "snaka/sandbox"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
